# 开发验收记录

日期：2026-10-24。以下保留各开发预览版本的实现与验证历史。

## 0.3.0 表单学习与本地复用开发预览

新增本地表单模板：侧栏逐字段核对后保存，主入口“识别并填写”优先重新定位模板。完全适用的本站模板使用当前简历直接本地填写，AI 关闭时也可复用；部分适用时只为待识别区域及必要上下文准备发送预览。跨站点候选另需用户核对确认，不能仅凭北森域名直接填写。

模板保存脱敏字段和区域依据、参数化经历路径、控件类型及本地自定义字段归属，不保存 value、HTML、临时编号或脚本。区域/经历结构变化、手动映射冲突和自定义引用失效要求核对。保存更新保留本次仍匹配的已确认字段及新核对字段，替换失效对应关系。管理页支持查看、改名、停用与删除。

数据库升级 v3；原型、v1/v2 数据、JSON 和加密备份迁移保留原资料、映射与设置，新增空模板集合。完整备份包含模板。模板执行增加保守的空原生控件重绑定：原父容器、静态依据、类型、区域和控件数量必须一致且替代目标唯一；整体重建和填写后再次重建仍要求重新核对，原 AI 布局执行不放宽节点校验。

新增模板引擎、数据与备份、管理及重绑定单元回归，以及真实扩展的虚构表单浏览器流程。本地通过 351 项单元/DOM/UI 测试和 28 项 Chromium 扩展回归（完整 27 项及追加浏览器重启场景）。类型、代码、格式检查通过，Chrome / Edge 构建与 ZIP 打包完成。远程 CI 结果见本次 PR。测试采用模型响应桩；尚未完成哈啰或第二家北森的真实模型及实站验收。原生日期/月控件沿用现有能力，自定义日期面板、无可访问关系的视觉地区选择器和添加经历仍需人工操作。

## 0.2.4 选择控件开发版

只读输入和包装控件可作为明确关联 ARIA 弹层的选择入口。新增异步单选列表与地区树驱动，本地进行同义匹配或完整行政层级导航；确认只限所属弹窗，缺少关联、存在歧义或状态变化时停止当前控件。只有明确的清空操作才能自动撤销，其余提示手动恢复；已有内容、用户预选、搜索词和后续编辑受到保护。

已关联弹窗的控件、选项、搜索词及已选摘要不进入 AI 布局请求；资料值仅在本地执行时使用。原生单选框点击产生的 input/change 不再误判为用户中断，用户指针及键盘操作仍会停止正在运行的选择。数据库和备份格式保持 v2。

通过 284 项单元/DOM 测试、24 项 Chromium 浏览器回归，类型、代码和格式检查通过，Chrome / Edge 构建与 ZIP 打包完成。新增场景使用虚构页面和模型响应桩；没有获得哈啰真实选择器 DOM 或在线模型验收结果。本版本在独立功能分支维护，0.2.3 标签与草稿安装包保持不变。

## 0.2.3 动态表单连续填写与空字段补充

移除填写过程中的整页布局指纹比对，改为目标控件、原始文字依据、层级、顺序和内容检查；新增校验提示或几何位置变化可继续，被替换或语义/内容改变的目标单独跳过。请求期间原始语义变化仍拒绝旧结果，不重绑定被替换节点。

有效的未匹配名称优先尝试唯一等义资料，确实缺少时新建空自定义字段。在侧栏输入一次后本地保存并填写（不支持的控件仅保存），后续复用且不重复创建；不生成默认事实、不保存站点映射、不发送新增内容或真实自定义 ID。数据格式保持 v2。

通过 238 项单元/DOM 测试、22 项 Chromium E2E，包括动态校验提示、独立跳过、字段新建/保存/再使用、隐私和撤销回归。类型与代码检查通过。测试使用虚构表单与模型响应桩，未取得真实哈啰页面的新一轮验收证据。

## 0.2.2 自定义等待与取消

AI 设置支持 1–86400 秒自定义等待或无限等待；旧设置保持 30 秒默认值，不改变资料 schema 版本。预览展示本次上限，等待中展示耗时并可主动取消，页面或资料变化也会中止请求。取消后不应用晚到响应。无限等待不改变服务商或网络的期限。

通过 206 项单元/DOM 测试和 22 项 Chromium E2E，以及类型和代码检查；新增覆盖默认/自定义期限、无限等待不建立期限、主动取消与晚到响应、设置持久化及备份兼容。使用响应桩和虚构资料，未调用在线模型。

## 0.2.1 识别进度、独立名称与常用资料

侧栏固定展示采集、等待发送确认、AI 请求、本地填写、完成、失败或页面/资料变化。完整请求可展开查看，确认按钮提前显示。失败不会停留在等待状态，提供重新采集入口。分别统计控件、有效名称、资料匹配和实际填写数量。

模型按控件逐项尝试命名，名称不依赖资料值或控件操作能力；无依据、冲突及遗漏项有明确原因。新增最高学历、最高学历对应学习形式、户口所在地、民族，默认为空且独立录入。v2 数据格式兼容 v1 与原型迁移，旧 JSON 和真实 v1 加密载荷恢复已覆盖。

通过 193 项单元/DOM 测试、21 项 Chromium E2E，以及类型、代码和格式检查。浏览器覆盖空资料与缺 key 命名、只读及自定义控件、模型遗漏与非法依据、补齐资料后的填写回读/撤销、四个资料字段编辑持久化、HTTP 错误、超时与权限拒绝终态。超时使用缩短的测试信号期限，权限拒绝模拟 API 返回，未覆盖系统原生弹窗拒绝操作。AI 均为响应桩，尚未调用在线模型或取得哈啰页面验收样本。

## 0.2.0 AI 布局识别与本地自动填写

新增独立布局采集与无填写值的资料 key 目录；AI 根据文字块、控件位置、层级和顺序做语义对应，不再依赖规则先确定标签。标准字段发送公开 key 与语义说明，自定义字段使用临时别名。发送前展示请求预览并支持导出布局 JSON；点击“确认识别并填写”后自动执行有效匹配项，本地取值、保护已有内容并支持撤销。

单次限制 500 个候选控件、200 KB 完整请求正文。校验模型返回引用及操作前页面、资料和控件状态；过期或冲突结果不会自动填写。顶层已展开表单为首版范围，复杂控件仍可能无法操作。数据库与备份格式不变。

通过 179 项单元/DOM 测试和 18 项 Chromium E2E，覆盖布局与 key 目录请求、确认后自动取值填写、已有值保护与撤销、单选后继续填写、页面/简历变化时拒绝过期响应，以及 AI 失败不回退自动填写。类型、代码与格式检查通过，Chrome / Edge 构建包生成。响应桩验证流程与隐私边界，不代表在线模型的语义识别质量。尚未取得用户登录后哈啰招聘页的真实布局样本，也没有配置在线模型验收结果；不宣称该页面已修复。人工验收步骤见 [测试说明](testing.md)。

## 0.1.2 AI 只定位字段

2026-10-24：AI 请求改为经过过滤的网页字段结构和临时资料字段编号/名称；不发送简历填写值、页面已有值、选项、HTML、截图、页面 URL 或本地资料路径。返回编号映射后由插件本地取值，预览确认再填写。AI 可理解所有候选字段，不限于规则未匹配项。页面文字过滤已知资料值和常见敏感模式，仍需人工核对预览。

移除导入页面的 AI 简历全文整理入口，保留本地 PDF/DOCX/TXT 提取、基础草稿和手工编辑。API Key 仅存会话、用于请求鉴权，不进入 AI 消息正文或备份。

本版通过 132 项单元/DOM 测试、15 项 Chromium E2E，以及类型与代码检查。新增覆盖嵌套标签和经历分组、请求内容脱敏、匿名编号白名单、拒绝脚本/填写值、实际请求与预览一致、本地取值后确认填写和撤销、请求期间修改简历后丢弃旧结果。浏览器 AI 响应采用拦截桩，没有调用在线模型，也不代表已验证真实企业页面的识别效果。0.1.0 中的 AI 结构化导入为历史功能，当前已移除。

## 已知行为边界

需先在招聘页展开或新增经历条目；不自动点击“添加经历”。iframe、Shadow DOM、封闭组件、缺少可访问关系的省市联动和文件上传需人工处理。部分可识别 ARIA combobox 能填入；只有明确清空操作的选择器可自动撤销，其余明确要求手工恢复组件状态。规则不确定时不默认勾选，用户可重新绑定。

普通本地资料库不加密；加密用于导出备份。卸载扩展前请备份，备份密码无法恢复。PDF 无 OCR；本地文本规则只提取有限基础字段，经历需在本地手工补充并核对。
