# 竞品基准测试模板

目标是比较Resume Companion、OfferLink、牛客网简历填写助手在相同任务上的填写质量。本文不包含任何实际测量结果，不可据此宣传领先。

## 统一条件

固定浏览器版本、插件版本、日期、机器、虚构简历和至少 30 个表单场景。每款插件使用干净浏览器资料，关闭其他填表扩展；明确 AI 是否开启、使用的模型及费用。站点、字段和已有值必须一致。首次配置时间与单次填表时间分开计量。模拟夹具与真实企业页面分别汇总。

对每个场景先人工标注：可填写字段、简历中存在对应资料的字段、应保留的旧值、需人工决定的字段。重复经历按每个具体字段计数。无法运行某款插件时标记“不适用 / 失败原因”，不可当作 0 分。

## 指标

- 正确覆盖率 = 正确自动填写的有资料字段数 / 所有可填且有资料字段数。
- 填写准确率 = 正确自动填写字段数 / 实际自动填写字段数；未填写时记不适用。
- 人工修改次数 = 自动填写后为纠错所需的字段修改数；补充漏填单独记录。
- 完成时间 = 开始识别至所有字段核对完成，包含修正，不包含人工提交。
- 首次体验时间 = 开始安装至第一次完成核对。
- 效率提升 = 1 − 插件完成时间 / 同场景纯手工完成时间。

90% 覆盖率、99% 填写准确率、50% 时间减少均为发布目标，尚不是测量结果。
