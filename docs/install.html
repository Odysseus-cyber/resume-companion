如何使用支持范围隐私说明
Start locally

先在自己的浏览器里试试

当前为开发预览版，暂无商店下载。拿到项目源码后，按以下步骤构建并加载。

1. 准备开发环境

安装 Node.js 22 或更高版本，以及 package.json 指定版本的 pnpm。在项目目录执行：

bash scripts/dev.sh install --frozen-lockfile
bash scripts/dev.sh build
bash scripts/dev.sh build:edge

脚本把缓存、临时文件和测试浏览器资料集中放在项目 .dev 目录。它不需要云账号或数据库。

2. 加载扩展

在 Chrome 的 chrome://extensions 或 Edge 的 edge://extensions 开启开发者模式，选择“加载已解压的扩展程序”，加载项目 .output/chrome-mv3 或 .output/edge-mv3 目录。

3. 准备资料

固定扩展图标，点击打开侧边栏，再打开资料管理页。手动建立简历或导入文本型 PDF / DOCX / TXT。逐项核对再保存，AI 无需开启。

4. 识别与核对

打开网申页面，再次点击扩展图标，识别当前页面。检查映射和拟填内容，选择需要填写的字段。填写后回到网页核对，必要时撤销。插件不会替你提交。

能直接用虚构演示吗？

可以在本地测试页面使用虚构演示简历。演示资料不会写入个人简历数据库，也不能用于真实招聘网站，避免误投。

以后怎样清理？

先导出加密备份并停止开发服务。项目的清理脚本提供预览、生成产物清理和完整依赖清理模式；具体见 docs/development.md。需要时在测试浏览器中移除扩展。

浏览器重开后 API Key 为什么没有了？

API Key 仅保存在扩展会话中，需要时重新输入。核心本地功能不受影响。
