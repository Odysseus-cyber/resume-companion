## 商店文案草稿

**名称：** Resume Companion

**短描述：** 本地保存简历，预览并辅助填写网申表单。支持字段修正与撤销，由你核对和提交。

**完整描述：**

Resume Companion帮助校招和实习求职者减少重复填写。无需注册，在浏览器本地管理多份简历；打开网申页面后预览字段对应关系，选择需要填写的内容。已有内容默认保留，可记住手动字段绑定，并撤销本次未被后续手改的内容。

支持文本型 PDF / DOCX / TXT 本地提取、密码加密备份。可选接入你自己的 HTTPS AI 服务定位字段；只发送经过过滤的字段结构与资料字段名称，填写内容由插件本地取出，每次发送前展示内容，API 费用由服务商收取。AI 默认关闭，核心填写无需项目后台。普通本地库不加密，卸载前请备份。

当前 Moka、北森、飞书为实验识别，具体范围见支持列表。复杂企业控件可能需手工填写。扩展不会自动提交申请。

## 权限用途草稿

| 权限                       | 用途                                   |
| -------------------------- | -------------------------------------- |
| storage                    | 保存本地简历、映射、设置及会话 Key     |
| activeTab                  | 用户点击后读取当前标签页表单           |
| scripting                  | 注入本地打包的表单扫描和填写逻辑       |
| sidePanel                  | 提供预览、绑定、填写与撤销界面         |
| 可选 HTTPS 域权限          | 需要时访问用户选定站点或配置的 AI 服务 |
| 可选 localhost / 127.0.0.1 | 本地虚构演示与测试页面                 |

按最终打包 manifest 和实际行为填写商店数据声明。启用 AI 会发送用户确认的经过过滤的网页字段结构与资料字段名称，不能笼统声明“从不向任何第三方发送数据”。招聘网站可能读取填入其页面的资料，即使用户还未点击提交。

## 截图与审核步骤

准备真实构建截图：侧边栏预览、多个简历版本、手动绑定、导入核对、加密备份。只用虚构资料。图标由 `public/icon/` 构建提供，截图尺寸按提交时商店要求准备，不把静态说明页示意图当成真实功能截图。

审核员无需注册：安装扩展 → 打开资料管理 → 输入虚构姓名与邮箱 → 打开本地测试页 → 识别 / 预览 / 填写 / 撤销。AI 为可选，不要求审核员提供个人付费 Key；本地核心功能可独立验证。

## 发布流水线

在同一 commit 运行类型检查、代码检查、单元测试、浏览器回归和双浏览器构建，完成独立资料目录中的安装 / 升级检查。`pnpm zip` 生成两种安装包；确认包内包含第三方许可证，且不存在真实资料或密钥。

GitHub 标签与源码版本一致。由版本标签流水线生成 draft Release，维护者核对后公开；将同一批经过验证的包提交商店。Release Notes 说明新增行为、验证环境、兼容范围、已知问题和备份建议。失败版本不更新用户数据格式；有迁移时先完成旧备份回归。

## 静态站点

`docs/` 包含无外部字体、脚本或分析 SDK 的静态说明页面，可直接本地打开。后续可单独部署至 GitHub Pages 并把隐私政策 URL 填入商店；本次仅推送源码，不开启 Pages。部署时保留开发预览 / 支持范围的真实状态。
