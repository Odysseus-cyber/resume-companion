# 维护路线

当前归档基线：0.2.3；当前开发版本：0.3.0 表单学习与本地复用，包含 0.2.4 选择控件改动。源码、问题与 PR 统一在 [Odysseus-cyber/resume-companion](https://github.com/Odysseus-cyber/resume-companion) 维护。

## 当前方向：首次学习，后续本地复用

- 用户核对后保存模板，后续优先本地重新定位、读取当前简历和填写。关闭 AI 也能复用；结构变化时只让 AI 处理待识别区域，发送前继续预览确认。
- 以哈啰作为首个实站验收对象，再验证另一家北森页面。分别记录首次和再次填写的 AI 请求数、正确填写数、人工修正数和耗时；跨企业候选先由用户核对。
- 使用通用字段/区域匹配与控件驱动沉淀能力，不把域名识别视为整张表单支持。不发布未经实测的跨企业迁移率。
- 数据库 v3 与完整备份保存本地模板。云同步、社区模板市场、自动投递和后台定时任务不在本轮范围。

## 后续：真实控件样本与驱动补齐

- 优先取得哈啰招聘页面的脱敏控件样本，适配地区选择器的搜索、省市区层级、选择、确认与回读。AI 只识别结构和字段含义，资料值与选项匹配留在本地。
- 增加最高学历、学习形式、民族等自定义下拉框适配。当前开发分支增加了绑定 ARIA 弹层的通用驱动，等待异步选项并在本地做有限同义匹配；地区驱动按完整省市区路径导航。歧义选项留给用户核对，不猜测缺失资料。
- 保留已有内容，区分正常弹窗变化与真正失效的目标；能恢复原状态时提供撤销，无法可靠恢复时明确提示。
- 每类控件附虚构 HTML 样例、成功及失败回归。`tests/fixtures/choices.html` 使用独立的学历列表、地区树和确认按钮复现操作流程；它不是哈啰页面的结构样本。原生日期/月控件已支持，自定义日期面板和无可访问关系的视觉选择器仍待采样。尚无经过真实验证的添加经历入口，由用户先展开/添加。经用户参与的真实页面验收后才更新企业支持列表，0.2.3 归档包不包含这些后续改动。

## 后续验证

补充真实模型识别、Chrome / Edge 全新安装与升级、小规模用户内测及竞品对比记录。只有实测结果可用于兼容与效果宣传。

## 迭代与发布

功能分支 → PR → 类型检查、代码检查、单元与浏览器回归、双浏览器构建 → 合入 main。更新版本号与 CHANGELOG 后创建相同版本标签，由 CI 生成草稿 Release；维护者核对后公开。缓存与浏览器资料仅存本地，不提交仓库。

不设置自动修改代码或定时维护任务。商店发布及说明网站部署另行安排。
