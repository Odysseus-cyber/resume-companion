# 维护路线

当前基线：0.2.3 开发预览。源码、问题与 PR 统一在 [Odysseus-cyber/resume-companion](https://github.com/Odysseus-cyber/resume-companion) 维护。

## 下一步：招聘网站选择器

- 优先取得哈啰招聘页面的脱敏控件样本，适配地区选择器的搜索、省市区层级、选择、确认与回读。AI 只识别结构和字段含义，资料值与选项匹配留在本地。
- 增加最高学历、学习形式、民族等自定义下拉框适配。歧义选项留给用户核对，不猜测缺失资料。
- 保留已有内容，区分正常弹窗变化与真正失效的目标；能恢复原状态时提供撤销，无法可靠恢复时明确提示。
- 每类控件附虚构 HTML 样例、成功及失败回归；经用户参与的真实页面验收后才更新支持列表。当前版本尚未完成以上适配。

## 后续验证

补充真实模型识别、Chrome / Edge 全新安装与升级、小规模用户内测及竞品对比记录。只有实测结果可用于兼容与效果宣传。

## 迭代与发布

功能分支 → PR → 类型检查、代码检查、单元与浏览器回归、双浏览器构建 → 合入 main。更新版本号与 CHANGELOG 后创建相同版本标签，由 CI 生成草稿 Release；维护者核对后公开。缓存与浏览器资料仅存本地，不提交仓库。

不设置自动修改代码或定时维护任务。商店发布及说明网站部署另行安排。
